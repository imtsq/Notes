# 近反义
## 一级辨析
:::info
近义词示例：

不知自量：自大

反义词示例：

清新：污浊



<font style="color:#1DC0C9;">当前词汇考察类型</font>：

1. 简单词语（两到三个字词语，如 自大）
2. 成语
3. 诗句
4. 俗语（如：单丝不成线： 独木不成林）

<font style="color:#DF2A3F;">tips</font>:大多数近义词反义词考察是<font style="color:#DF2A3F;">混搭</font>，如：不自量力：自大 这种简单词：词语/诗句等混搭

:::
