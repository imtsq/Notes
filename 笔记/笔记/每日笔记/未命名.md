# 积累

1. 托底：托底”指作为最后保障，确保事物不出现最坏结果

2. 必要”指不可缺少的

3. 推诿”指把责任推给别人

4. 不妥协”强调立场坚定

5. 肃杀：秋冬时节草木凋零、寒气凛冽的自然景象

6. **相提并论**：指将不同情况或性质的人或事放在同等的地位来对待。
**等量齐观**：指把有差别的事物不加区别地同等看待。
**一概而论**：指用同一标准来评论或看待，指处理事情、问题不作具体分析，笼统地同样看待。
**同日而语**：指把相同的人或事物放在同一时间比较，放在一起谈论或看待。
**望其项背**：指看到别人的颈项和后背，指可以赶得上或能相比的，常用于"难以望其项背"的表述中。
**后来居上**：原指资格浅的、新进的人反居资格老的人之上，后指后来的胜过原来的，后辈胜过前辈。
**平起平坐**：比喻地位或权力相当。
